# Sleep_app

## Aperçu

Prototype statique du carrousel d’onboarding Sommeil & Récupération basé sur Swiper. Ouvre simplement `index.html` dans un navigateur ou lance un petit serveur local pour tester les interactions.

## Démarrage rapide

```bash
python -m http.server 8000
# puis visite http://localhost:8000
```

Consulte `guide-integration-swiper.md` pour les détails d’intégration et de personnalisation.
